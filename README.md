## 💡 About the Project

Welcome to my Machine Learning Classification project! 🚀

This project demonstrates a practical machine learning workflow using Python. It explores a student lifestyle dataset and applies different classification algorithms to learn how models can be trained, evaluated, and compared.

From exploring the data to tuning model parameters, this project helped me practice important concepts in data analysis and supervised machine learning.

## 🎯 Project Objectives

- 🔍 Understand the dataset through exploratory data analysis.
- 🧹 Prepare the data for machine learning.
- 📊 Explore relationships and patterns in the available features.
- 🤖 Train multiple classification algorithms.
- 📏 Evaluate and compare model performance.
- ⚙️ Apply hyperparameter tuning using GridSearchCV.

## 📂 Dataset

📄 **Dataset:** `student_lifestyle_100k.csv`

The dataset is used for exploring student-related information and building classification models.

> 📌 Ensure the CSV file is uploaded to the repository and that its filename matches the path used in the notebook.

## 🔄 Machine Learning Workflow

| Stage | Description |
|---|---|
| 🔵 01. Data Loading | Load the CSV dataset using Pandas |
| 🟣 02. Data Exploration | Inspect the data and explore patterns |
| 🟢 03. Preprocessing | Prepare features and apply required transformations |
| 🟡 04. Train-Test Split | Separate training and testing data |
| 🟠 05. Model Training | Train different classification algorithms |
| 🔴 06. Evaluation | Compare performance using evaluation metrics |
| 🟤 07. Optimization | Search for suitable parameters using GridSearchCV |

## 🧠 Classification Algorithms

The notebook explores the following algorithms:

  <img src="https://img.shields.io/badge/KNN-55A868?style=flat-square" />

- **Logistic Regression:** A classification algorithm that estimates class probabilities.
- **K-Nearest Neighbors (KNN):** Predicts classes using nearby data points.
- **Support Vector Machine (SVM):** Finds a decision boundary to separate classes.
- **Decision Tree:** Uses feature-based decisions to classify observations.
- **Random Forest:** Combines multiple decision trees.
- **Gaussian Naive Bayes:** Uses Bayes' theorem with a conditional independence assumption and Gaussian feature distributions.
